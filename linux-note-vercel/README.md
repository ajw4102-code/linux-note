# 리눅스 노트

로그인 없이 브라우저에서 사용하는 리눅스 명령어 학습 터미널입니다.

## GitHub → Vercel 배포

1. 이 폴더의 파일을 GitHub 새 저장소에 업로드합니다.
2. Vercel에서 **Add New → Project**를 선택합니다.
3. GitHub 저장소 `linux-note-vercel`을 Import합니다.
4. Framework는 **Next.js**, Install Command는 `npm install`, Build Command는 `npm run build`로 둡니다.
5. Deploy를 누릅니다.

학습 진도와 가상 파일은 로그인 없이 사용하기 위해 현재 브라우저의 localStorage에 저장됩니다. 다른 컴퓨터와 자동으로 동기화되지는 않습니다.
